# CodeSpotlight

An AI-integrated Flutter Web portfolio showcase — turns GitHub repos into stunning Bento Box project cards with AI-generated technical case studies, live deployment heartbeats, and interactive visualizations.

## Structure

```
CodeSpotlight/
├── frontend/    ← Flutter Web app (Firebase Hosting)
├── backend/     ← Node.js / Express API (Render / Vercel)
├── projectplan.md
└── tasklist.md
```
